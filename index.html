Cách kết nối API (để liệt kê/tìm — file luôn tải thẳng CDN)
① Userscript (khuyến nghị) — cài tiện ích Tampermonkey, rồi thêm file pawcrawl-bridge.user.js. Nó gọi API bằng chính trình duyệt bạn nên không dính challenge. Xong sẽ hiện “userscript đã kết nối”.
② Proxy URL (dự phòng) — dán URL Cloudflare Worker. Lưu ý pawchive thường chặn IP Worker (challenge DDoS-Guard) nên cách này hay lỗi 404.

Chưa kết nối được API. Cài userscript pawcrawl-bridge (khuyến nghị) hoặc đặt Proxy URL — bấm ⚙ Cấu hình. Nếu vừa cài userscript, hãy tải lại trang.
